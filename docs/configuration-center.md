# 配置中心使用说明

<!-- 说明配置中心的操作、导入格式、检查范围与数据备份。 -->

配置中心管理 Skill、MCP、Prompt、大模型和运行平台。没有登录，也不需要数据库。启动方式见[README](../README.md)。

## 配置与保存

左侧选择分类，右侧搜索、新建、编辑或删除。每条配置有稳定 ID 和 revision；修改时校验版本，避免两个窗口互相覆盖。保存后刷新页面或重启服务仍可读取。

列表中的启用开关支持五类资源，状态保存在本机；旧配置默认启用。停用保留配置内容、凭据和 Skill 配套文件，编辑也会保留当前状态。本阶段只管理资源的启用状态，尚未接入执行引擎；手动检查仍可使用，也不会更改 Codex 等客户端的原生配置。切换会更新版本并清除旧检查结果，原生资源 JSON 可使用 `enabled: false` 导入停用项。

列表中的检查/测试针对已保存版本。编辑保存后，旧检查结果失效；需要重新检查。大模型编辑窗口额外支持当前草稿的临时测试，不会自动保存连接、凭据或测试结果；更改参数后提示结果过期。列表中的“检查通过”仅表示对应检查范围通过，不表示 Agent 任务已经执行成功。

MCP 和运行平台的环境变量、MCP 请求头以及模型 API Key 会分离到私密文件；编辑页不回显原值。已有字段的空值表示保留；勾选清除或删除对应键后再保存，可移除活动凭据引用。不要把密钥写进名称、描述、URL、命令参数或 Skill/Prompt 正文。

运行平台的默认工作目录可留空，默认使用数据根目录；相对路径也从数据根目录解析。平台命令可留空，分别使用 codex、claude、dsh。同一平台可保存多份配置。本阶段不修改这些客户端的全局配置或登录文件。

## 大模型连接与目录

一条大模型资源代表一个 API 连接：配置协议根地址、认证和一个或多个模型。API 协议明确区分 OpenAI Chat Completions、OpenAI Responses 与 Anthropic Messages。模型 ID 是请求中发送的标识；显示名称只影响界面。目录必须有默认模型，可逐条添加、删除和展开能力配置。

上下文窗口和最大输出支持正整数或十进制 K/M 简写（128K=128000，1M=1000000）；留空代表未声明。文本/图片是用户声明的输入能力，文本连通性测试不验证图片或上下文上限。Chat/Responses 可设置每模型的 off/minimal/low/medium/high/xhigh 档位到 API 参数值的映射；仅添加提供商支持的档位。off 留空表示不发送推理参数，不保证端点关闭思考。Anthropic 的思考参数暂不适配，切换协议时需显式移除已有通用映射。

“获取可用模型”读取端点目录，只返回候选，勾选后追加，不覆盖已有同 ID 模型或手工能力。发现失败不等于不能推理，可继续手动填写并测试。编辑时 API Key 留空保留已存值，勾选清除后测试也不再使用旧密钥。

点击单模型“测试连接”后，先展示测试消息和费用提示，再明确开始。消息固定为：

> 请只回复：连接成功。不要执行命令或修改文件。

一次点击只发送一个无工具的文本生成请求，不自动重试，输出预算最多 1024 token（模型声明更低上限时使用更低值）。Chat 默认使用 max_completion_tokens；旧端点需要时可在接口兼容设置中显式选择 max_tokens。其他协议使用对应输出字段。自定义地址前缀会保留；Anthropic 根地址按需追加 /v1。取消和关闭窗口释放本地连接，但远端可能已经处理请求并产生少量费用。

已保存版本的测试结果按模型和 revision 登记，列表只代表最近测试的模型，不意味着整个目录通过。只有按约定收到“连接成功”才通过；其他文本、空响应、工具调用和截断回复显示部分确认。旧单模型 openai/anthropic 配置可读取和导入，保存时转换为新目录；旧空模型目录需补全。历史模型列表检查不当作真实文本测试。

## 导入格式

先选择文件或粘贴 JSON，再解析预览。预览不保存配置、不启动程序、不连接服务。确认时会再次校验来源。

| 类型 | 支持的输入 |
| --- | --- |
| Skill | SKILL.md、完整目录或 ZIP；保留配套文件和包内相对路径 |
| MCP | 合法的 mcpServers JSON，支持文件或粘贴 |
| Prompt | .md、.txt 或本平台资源 JSON |
| 大模型、运行平台 | 本平台资源 JSON，支持文件或粘贴 |

Skill 的 SKILL.md 需要 YAML frontmatter，包含标准 name 和 description。name 使用小写字母、数字和单连字符，最多 64 个字符；显示名称可另外修改。ZIP 不能包含路径越界、符号链接或嵌套 Skill。编辑正文会保留包内配套文件；本阶段不提供多文件 IDE。

MCP 示例：

```json
{
  "mcpServers": {
    "example": {
      "type": "http",
      "url": "https://mcp.example.com/mcp",
      "headers": {}
    }
  }
}
```

这个示例地址需替换后才能连接。stdio 使用非空 command、字符串数组 args、字符串映射 env 和可选 cwd；远程服务使用 url 和 headers。type 为 stdio、http 或 sse，分别表示本地进程、Streamable HTTP、旧版 SSE。未提供 type 时，根据 command 或 url 推断；二者同时提供会报错。未知扩展字段会在预览提示，并仅存入私有来源副本，不视为已经生效。

本平台资源 JSON 可以是单个 `{ "name": "名称", "config": { ... } }`，也可以是 `{ "resources": [ ... ] }`。导入忽略外部 ID，生成自己的 ID。可直接试用[示例文件](./examples/)；其中模型凭据为空，需要自己填写。

JSON 示例保持标准格式，用途如下：

| 文件 | 用途 |
| --- | --- |
| [mcp.json](./examples/mcp.json) | 演示 mcpServers 格式的远程 MCP 连接配置。 |
| [model.json](./examples/model.json) | 演示一个 OpenAI Chat Completions 连接管理多个模型。 |
| [platforms.json](./examples/platforms.json) | 演示 Codex、Claude Code 和 DeepSeek Harness 的批量平台配置导入。 |

遇到同名配置，默认跳过已有项；也可选择替换或另存。替换保留原 ID，另存创建新 ID 并区分名称。如果已有多个同名项，替换会要求先处理重名。批量结果逐项显示保存、跳过和失败，不提供跨整个批次的事务。

## 检查范围

| 类型 | 实际检查 | 不代表 |
| --- | --- | --- |
| Skill | frontmatter、文件结构、Markdown 相对文件引用 | Skill 内容在所有平台上都有效 |
| Prompt | 正文与双花括号变量声明 | 指令效果或模型输出质量 |
| MCP | 协议握手及已声明的 tools/resources/prompts 能力发现 | 业务工具执行成功 |
| 大模型 | 选择一个模型发送固定文本生成请求，确认响应；获取目录是独立操作 | 全目录、图片、全部推理档位及最大上下文都已可用 |
| Codex、Claude Code | 命令、版本、CLI 支持的只读认证状态 | Agent 执行或模型调用成功 |
| DeepSeek Harness | 命令、版本 | 认证或执行成功；本阶段没有假定通用的认证查询接口 |

认证失败、模型不可用、参数/协议不匹配、限流、连接失败和超时分别报告。MCP 不调用工具；模型测试发送上述固定生成请求。点击取消或关闭检查窗口会取消本地请求；取消结果不保存，模型远端可能已产生费用。模型发现不支持时保留手工配置入口；平台无法查询认证时仍显示部分确认。

2026-11-22 本机验证：Codex 0.171.0-alpha.13、Claude Code 2.1.118 的版本及已有认证状态查询通过；dsh 未安装。DeepSeek Harness 的真实已安装环境检查尚未验证。测试还使用受控服务验证了三种 MCP 传输、模型发现、认证失败、超时与 HTTP 断开后的进程清理。

## 数据与备份

普通配置在 doc/config/ 按 ID 保存；Skill 使用 `skills/<id>/resource.json` 和 `<标准包名>/SKILL.md` 及配套材料。私密值在 doc/private/secrets.json，导入来源在 doc/private/sources/。详见[固定目录约定](../doc/README.md)。

私密文件与普通响应分离，但目前属于本机明文存储，没有引入系统凭据库或加密。来源副本可能包含导入时的旧凭据。在应用停止后备份整个数据根目录，恢复时保持 config/ 和 private/ 配套；只复制普通配置无法恢复凭据。

同一数据根目录只运行一个后端实例；单进程内协调写入，更新核对 revision，文件使用临时写入和替换。文件多步操作不等于数据库事务，进程突然退出和磁盘故障仍需依赖备份。应用默认仅接受本机访问，并拒绝外部页面的跨域请求。

画布、并发链路、运行历史和恢复状态机留待下一阶段设计，本阶段没有预建相应存储或执行服务。
