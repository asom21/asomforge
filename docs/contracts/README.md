# 接口与产物契约

<!-- 说明后续 Agent 消息、正式产物和交接契约的规划。 -->

本目录预留给后续契约设计，当前不包含具体 Schema 或接口定义。

## 规划范围

- 前后端 API 与事件的数据结构及版本。
- Agent 正式交付物的内容结构、必填项与校验规则。
- 上游产物到下游输入的映射及来源记录。
- A2A 对接字段与平台内部对象之间的映射。

## 基本约定

- 消息用于沟通，产物用于正式交付，不默认互相替代。
- 交接契约有明确版本，运行记录能够追踪实际使用版本。
- 结构校验和业务验收分开，字段合法不代表内容满足需求。
- 前端类型生成、后端校验和运行时接入应基于明确契约保持一致。

业务背景参见 [架构说明中的产物交接章节](../../AsomForge-项目说明与架构设计.md#7-产物交接与-a2a)。
