# 简约轻科技界面与主题设计

<!-- 记录用户确认的配置中心视觉方向、主题行为和验收范围。 -->

## 已确认方向

2026-11-25，用户确认以简约为主，允许少量渐变和动态反馈，增加深浅主题切换。本说明记录此前已确认的设计，不扩大业务范围。

## 方案与取舍

讨论过精密工作台、未来控制台、轻盈科技三种方向。采用精密工作台：中性灰白与石墨色背景、电蓝色强调、统一图标和清晰排版；吸收少量蓝色渐变和微光细节。不采用大面积霓虹、网格、玻璃背景和持续装饰动画。

## 页面和组件

- 五类配置页面及 Tool 占位页共用壳层。侧栏保持资源分类，收紧重复的工作空间信息；顶部显示当前分类和主题按钮，连接状态统一留在侧栏。
- 正文和导航以 14–15px 为主，辅助信息以 12–13px 为主；中性边框、8–16px 圆角、统一间距和清晰文字对比。
- 无配置时展示紧凑引导，隐藏空表头、搜索筛选和无意义页脚；加载、失败、筛选无结果分别反馈，已有资源时保留搜索、状态筛选、启用、检查、编辑和删除。
- 新建、编辑、导入、检查、错误反馈、通知和原生表单控件统一适配深浅主题。不修改资源持久化和后端契约。

## 主题和动态

- 首次跟随系统；右上角太阳/月亮按钮切换，记住用户选择。只在 localStorage 保存主题偏好，不保存资源或凭据。
- 存储不可用时仍可切换；无手动选择时响应系统主题变化。尽早应用主题，减少首次加载闪白。
- 浅色灰白底、白面板；深色石墨底、深灰面板。蓝色只用于重点。
- 渐变限于品牌、主按钮、空状态的淡光晕。普通交互与弹窗过渡约 150–200ms；按用户后续要求，手动主题切换以按钮中心为圆心，用约 550ms 展开新主题，半径覆盖视口最远角。深浅切换采用同一方向的揭示效果，快速点击不叠加过渡。检查中可短暂呼吸，结果静止。遵循 prefers-reduced-motion；减少动态或浏览器不支持视图过渡时直接切换。

## 验收

浏览器验证浅/深主题、刷新记忆、系统偏好、存储禁用、五类页面及弹窗、真实资源列表与筛选、窄屏和减少动画。执行前端格式、类型、构建检查；浏览器验证 3000 的页面与 8000 的 API 代理。保持现有端口和启动文档改动，不自动提交或推送。
