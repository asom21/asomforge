# 本地数据目录

<!-- 约定本地配置、私密数据和日志的固定存储目录。 -->

本目录保存 AsomForge 的个人本地数据，与保存项目文档的 [docs/](../docs/README.md) 分开。

状态：配置中心已使用此目录保存本机文件。

## 固定结构

```text
doc/
├── README.md
├── config/
│   ├── skills/       # Skill 目录，保留 SKILL.md 与配套文件
│   ├── mcp/          # MCP 连接配置
│   ├── prompts/      # Prompt 内容与变量配置
│   ├── models/       # 大模型服务连接与模型配置
│   ├── platforms/    # Agent 运行平台配置
│   └── tools/        # Tool 预留，本阶段不实现
├── private/          # 本机私密数据，普通配置通过引用使用
└── logs/             # 本地应用日志
```

以后增加配置类型，在 config/ 下添加对应的类型目录。目录表示数据用途，不要求为每类资源创建独立服务或通用插件框架。

## 保存约定

- 第一阶段使用本地文件存储，不引入本地或云端数据库。
- 默认数据根目录是项目根目录下的 doc/。后端入口统一管理数据根目录，允许通过本机启动配置调整，业务代码不散布本机绝对路径。
- 普通配置按条目分别保存为 JSON 文件。Skill 保留标准目录及其内部相对引用，普通资源按 ID 命名；Skill 使用 skills/<id>/resource.json 与 <标准包名>/SKILL.md 及配套材料。
- 敏感凭据与普通配置分别保存，普通配置仅保存引用。私密值在 private/secrets.json，原始导入来源在 private/sources/；当前为本机明文文件，不在仓库中写入真实凭据。
- MCP 导入首先支持常见的 mcpServers JSON 配置。导入解析与字段校验完成后再保存，连接测试单独发起；其他客户端格式不视为已支持。
- 本文件是可提交的目录说明，其余本机数据由项目根目录的 .gitignore 排除。拉取项目后，应用入口按约定创建缺少的数据目录，目录为空不代表已经实现配置能力。

当前导航规划包括 Skill、MCP、Tool、Prompt、大模型和运行平台。Tool 保留导航与目录位置，本阶段不提供其配置读写或执行能力。

后续运行历史、产物与恢复材料的存储方式另行设计，当前不预建相应的数据结构或数据库兼容层。
